Вариант: 3 (тема "Спорт и активность", цветовая гамма зелёно-чёрная)

Цель работы
Освоить базовую структуру HTML-документа, семантические теги, работу с текстом, списками, ссылками, изображениями и формами.

Состав работы
index.html - HTML-страница "О себе"
style.css  - таблица стилей
avatar.jpg - изображение для страницы

Структура страницы
1. header - шапка с именем, фамилией и заголовком страницы.
2. main - основной контент:
   - секция "Обо мне" с изображением (атрибуты src, alt, width, height);
   - секция "Навыки" - маркированный список спортивных навыков;
   - секция "Проекты" - нумерованный список соревнований и достижений (4 пункта);
   - секция "Обратная связь" - форма с полями "Имя" (type="text"), "Email" (type="email"), "Сообщение" (textarea) и кнопкой отправки. У всех полей заданы атрибуты name и placeholder.
3. aside - боковая панель с информацией о виде спорта и ссылками.
4. footer - подвал с копирайтом и годом.

Оформление
Стили вынесены в отдельный файл style.css. Использована зелёно-чёрная цветовая гамма в соответствии с вариантом. Предусмотрена адаптация под узкие экраны.

Проверка
Разметка и стили проверены через W3C Validator (validator.w3.org). Ошибок и предупреждений не обнаружено.

Запуск
Открыть файл index.html в браузере.
