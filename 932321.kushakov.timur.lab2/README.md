## Цель работы

Научиться подключать стили, работать с селекторами, типографикой, цветами, отступами, позиционированием и псевдоклассами.

## Состав работы

```
index.html            - страница "О себе" из ЛР №1 с обновлённым оформлением
style.css             - основная таблица стилей
assets/img/avatar.jpg - изображение для шапки
assets/icons/*.svg    - иконки соцсетей (Telegram, VK, Strava)
```

## Способы подключения стилей

1. Внешний файл `style.css` - основной стиль страницы.
2. Inline-стиль - изображению в `header` задан атрибут `style="border-radius: 50%;"`.
3. Внутренний блок `<style>` - стили маркированного списка "Навыки": стандартные маркеры отключены (`list-style: none`), вместо них добавлен символ через `::before`, задан отступ слева.

## CSS-переменные

В `:root` объявлены переменные для цветов (основной зелёный `--color-primary`, акцентный чёрный `--color-accent`, вспомогательные оттенки), шрифтов (`--font-main`, `--font-heading`), радиуса скругления и длительности переходов.

## Позиционирование

| Тип        | Элемент                               |
|------------|---------------------------------------|
| `static`   | `main` (указано явно)                 |
| `relative` | `aside`, ссылки внутри блока `.social` |
| `absolute` | бейдж "Бег" в правом верхнем углу `aside` |
| `fixed`    | блок иконок соцсетей `.social` в правом нижнем углу экрана |

## Состояния элементов

- Ссылки: `:hover` (смена цвета, снятие подчёркивания), `:active`, `:focus` (обводка), `:visited`.
- Поля формы: `:hover`, `:focus` (подсветка рамки и тень).
- Кнопка отправки: `:hover`, `:focus`, `:active` (уменьшение масштаба).
- Иконки соцсетей: `:hover` - `transform: scale(1.2) rotate(5deg)`, `:active` - обратный поворот.

Все переходы выполняются плавно через `transition`.

## Контрастность

Контраст пар "текст - фон" не ниже 4.5:1: белый текст на зелёном фоне шапки - 5.1:1, светлый текст на тёмном фоне - 13.9:1, зелёные заголовки на тёмном фоне - 6.1:1.
