## Исходные данные

Массив из 7 чисел - вес посылок, которые нужно доставить (в кг):

```js
const packages = [1.5, 8, 3, 12, 0.5, 6, 22];
```

Пороговые значения вынесены в константы:

| Константа              | Значение | Назначение                                 |
|------------------------|----------|--------------------------------------------|
| `HEAVY_LIMIT`          | 5        | тяжёлая посылка: вес > 5 кг                |
| `LIGHT_LIMIT`          | 2        | лёгкая посылка: вес <= 2 кг                |
| `SECOND_COURIER_LIMIT` | 50       | общий вес, при котором нужен второй курьер |

## Функции

| Функция                         | Что делает                                        |
|---------------------------------|---------------------------------------------------|
| `findHeaviestPackage(weights)`  | возвращает вес самой тяжёлой посылки              |
| `filterHeavyPackages(weights)`  | возвращает новый массив только с посылками > 5 кг |
| `calculateTotalWeight(weights)` | возвращает общий вес посылок                      |

Все три функции реализованы через цикл `for` и условие `if`, без встроенных методов `Math.max`, `filter` и `reduce`.

## Логика работы

1. Через `prompt` запрашивается имя пользователя. Если нажата "Отмена" или введена пустая строка, используется обращение "курьер".
2. Отдельным циклом по исходному массиву считается количество лёгких посылок (<= 2 кг) и их доля в процентах от общего количества.
3. С помощью функций вычисляются общий вес, массив тяжёлых посылок, их суммарный вес и самая тяжёлая посылка.
4. Через `alert` выводится приветствие и сообщение об общем весе груза.
5. В консоль через `console.log` выводятся доля лёгких посылок и их количество.
6. Если общий вес больше 50 кг, в консоль через `console.warn` выводится предупреждение.

## Пример работы

Имя: Тимур.

Сообщение `alert`:

```
Здравствуйте, Тимур!
Общий вес груза - 53 кг, из них 48 кг - тяжёлые посылки.
```

Вывод в консоль:

```
Вес посылок (кг): [1.5, 8, 3, 12, 0.5, 6, 22]
Самая тяжёлая посылка: 22 кг
Доля лёгких посылок: 28.6%
Количество лёгких посылок: 2
Требуется помощь второго курьера
```

Последняя строка выводится через `console.warn` и выделяется в консоли как предупреждение.

Расчёт: общий вес 1.5 + 8 + 3 + 12 + 0.5 + 6 + 22 = 53 кг. Тяжёлые посылки 8, 12, 6, 22, их вес 48 кг. Лёгкие посылки 1.5 и 0.5, это 2 из 7, то есть 28.6%. Общий вес больше 50 кг, поэтому выводится предупреждение.

При нажатии "Отмена" в окне `prompt` приветствие выглядит так: "Здравствуйте, курьер!".

## Отладка

Отладка выполнялась в инструментах разработчика браузера (F12).

- **Console.** Проверка вывода `console.log` и `console.warn`, а также отсутствия ошибок при загрузке скрипта. В консоли можно вызвать функции вручную, например `findHeaviestPackage(packages)` или `filterHeavyPackages([1, 6, 10])`, и сравнить результат с ожидаемым.
- **Sources.** В файле `script.js` ставится точка останова (breakpoint) на строке внутри цикла, например в `calculateTotalWeight`. После перезагрузки страницы выполнение останавливается, и на панели Scope видны текущие значения `weight` и `sum`. Кнопкой "Step over" (F10) цикл проходится по шагам.
- **Оператор `debugger`.** Аналог точки останова прямо в коде: при открытых DevTools выполнение останавливается на этой строке.
- **Промежуточный вывод.** Для проверки промежуточных результатов в консоль выводились исходный массив и самая тяжёлая посылка.
