## Поиск элементов

| Метод              | Где используется                                                         |
|--------------------|--------------------------------------------------------------------------|
| `getElementById`   | кнопки, контейнер карточек, сообщение о пустом списке                    |
| `querySelector`    | поиск заголовка, даты, иконки и описания внутри карточки                 |
| `querySelectorAll` | получение всех карточек для сохранения, восстановления и проверки списка |

## Манипуляции с DOM

**Добавление достижения.** Через два `prompt` запрашиваются название и дата в формате ДД.ММ.ГГГГ. Карточка создаётся через `document.createElement`: `<div class="card">`, внутри иконка-заглушка `<img>`, заголовок `<h3>`, дата `<time>` с атрибутом `datetime` и кнопка "Удалить". Готовая карточка добавляется в контейнер через `appendChild`. Если ввод отменён, в консоль выводится сообщение. При пустом названии или неверном формате даты показывается `alert`, карточка не создаётся.

**Удаление достижения.** Кнопки "Удалить" обрабатываются одним обработчиком на контейнере, поэтому работают и для новых карточек. При нажатии карточке добавляется класс `fade-out` (`opacity: 0`, `pointer-events: none`, плавный `transition`), после окончания анимации элемент удаляется из DOM через `remove()`.

**Скрытие и показ.** Кнопка "Скрыть все достижения" проверяет наличие контейнера через `getElementById` и переключает у него класс `collapsed` (`display: none`). Текст кнопки меняется на "Показать все достижения", атрибут `aria-expanded` обновляется. Повторное нажатие убирает класс. Если контейнера нет, в консоль выводится ошибка.

**Переключение темы.** Кнопка в шапке меняет класс `theme-dark` / `theme-light` у `<body>`. Цвета страницы заданы CSS-переменными, класс `theme-light` переопределяет их значения. Текст кнопки меняется на название темы, на которую можно переключиться.

## Сохранение в localStorage

| Ключ                | Что хранится                                                  |
|---------------------|---------------------------------------------------------------|
| `lab5-theme`        | выбранная тема: `"light"` или `"dark"`                        |
| `lab5-achievements` | массив карточек: название, дата, путь к иконке, alt, описание |

Список сохраняется после каждого добавления и удаления, тема после каждого переключения. При загрузке страницы тема и карточки восстанавливаются. Если в localStorage ещё ничего нет, показываются 4 карточки из HTML.

## Обработка ошибок

- Все элементы ищутся через функцию `getElement`, которая при отсутствии элемента выводит в консоль `Элемент не найден: #id`.
- Каждая часть скрипта (тема, карточки, скрытие) запускается отдельно. Если для одной части нет нужного элемента, остальные продолжают работать.
- Чтение и запись localStorage выполняются в `try...catch`. При повреждённых данных в консоль выводится ошибка, и показывается список по умолчанию.
- Записи из localStorage проверяются перед созданием карточки, некорректные пропускаются с предупреждением в консоли.

## Проверка

Разметка и стили проверены через W3C Validator, ошибок не обнаружено. Синтаксис скрипта проверен командой `node --check script.js`. В браузере проверены добавление, отмена ввода, неверная дата, удаление с анимацией, скрытие списка, переключение темы и восстановление состояния после перезагрузки. Горизонтальная прокрутка отсутствует на ширине 375, 768 и 1280 px.

## Запуск

Открыть файл `index.html` в браузере. Чтобы вернуть исходный список достижений и тёмную тему, очистить localStorage в DevTools (вкладка Application, раздел Local Storage).
